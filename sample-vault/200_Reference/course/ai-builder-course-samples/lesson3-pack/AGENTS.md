# 公司手冊 · AGENTS.md(示範)

> 課程 lesson 3 嘅示範公司手冊。所有人名、公司名都係虛構。

## 呢間「AI 公司」點運作
- CEO(你)定方向同批核;員工(agent)只做已經寫清楚嘅工作。
- 每位員工有自己嘅 SKILL.md,講明幾時用、要準備乜、會交返乜。
- 冇一個員工可以自己改 vault 或者對外發佈,一律出草稿等人批。

## 三條公司規矩
1. **有出處先算數** —— 交出嚟嘅數字要講得出邊度嚟,冇出處就標「待確認」。
2. **一件事一個負責人** —— 唔准兩個 agent 同時改同一份文件。
3. **交付前搵個唔知背景嘅人睇 10 秒** —— 睇唔明就即係未做完。

## 交接格式
每次交返嚟都要有:做咗乜 / 未做乜 / 點解 / 要你批乜。
