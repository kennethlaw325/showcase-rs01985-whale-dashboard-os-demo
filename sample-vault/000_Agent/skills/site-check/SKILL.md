# site-check

出街前逐版檢查連結、圖同載入速度,出一張可以逐項剔嘅清單。

## 幾時用
新版網站或者改版之後、交俾客之前。

## 要準備乜
要檢查嘅網址清單,同埋今次改咗邊幾版。

## 步驟
1. 列清楚要檢查邊幾版
2. 叫 AI 跑 /site-check
3. 逐項對返實際頁面,唔啱就標出嚟
4. 全部剔晒先交俾客

## 會交返乜
一張逐版清單:死連結、缺圖、載入慢過 3 秒嘅版,各自標明喺邊。
