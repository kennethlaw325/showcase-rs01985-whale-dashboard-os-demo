# invoice-check

對單:報價、發票、實收三邊夾唔夾得埋

## 幾時用
月尾對數,或者收到款項想核對

## 要準備乜
報價檔、發票、銀行月結單

## 步驟
1. 講清楚你要嘅結果
2. 叫 AI 跑 /invoice-check
3. 檢查輸出有冇出處、假設、待確認項
4. 確認咗先交去下一步
